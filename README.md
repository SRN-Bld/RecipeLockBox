# My Recipe Box

A personal website for storing recipes I've created and ones I find online.

## Story 1 (done): Save and view recipes
- Add a recipe with a name, cuisine, ingredients, steps, a link to the original, and my own notes
- See all saved recipes in a list
- Open a recipe to read it as simple text
- Edit or delete a recipe
- Recipes are saved in the browser, so they are still there after closing the page

Story 2 (done): Filter by cuisine and ingredients
Filter the list by cuisine
Pick the ingredients I have from a list built from my saved recipes
Each matching recipe shows a match percentage: 100% means it uses exactly the ingredients I picked, lower means it needs more or only uses some of them
Recipes are ranked best match first, and each shows which ingredients are still needed

## Coming next

- Story 4: Back up and move recipes between devices

## How to use
Open `index.html` in a browser, or visit the GitHub Pages link for this repository.
